# 🎬 MovieDex 🍿

> 🌌 A premium, dark-themed cinematic discovery platform.
> Your portal to movies, TV shows, and anime — powered by **The Movie Database (TMDB)** & **Firebase**. 🚀

Welcome to **MovieDex**! Step into a luxe "noir cinema" experience featuring 3D hero scenes, buttery smooth animations, and a rich crimson/gold aesthetic. 🎭

---

## ✨ What's Inside?

- **🎥 Cinematic Discovery:** Explore trending, popular, and top-rated titles with our stunning 3D animated landing page.
- **🔍 Deep Dives:** Get rich details on movies and shows—from cast & crew to trailers and where to stream. 🍿
- **👤 Your Personal Cinema:** Sign in to save favorites to your **My List** and seamlessly resume watching with your **Watch History**. 🎬
- **🔐 Secure & Fast:** Built with a serverless proxy to keep API keys hidden and Firestore rules to keep your data private. ⚡

---

## 🛠️ Tech Stack Magic

Built with modern web technologies:
- ⚛️ **React 19** + ⚡ **Vite 8**
- 🛣️ **React Router 7**
- 🎨 **Tailwind CSS 4**
- ✨ **GSAP** & 🧊 **Three.js** (for those sweet animations)
- 🔥 **Firebase** (Auth & DB)
- ☁️ **Vercel** (Hosting)

## 🚀 Quick Start

Ready to dive in? Here’s how to get MovieDex running locally:

### 1️⃣ Clone & Install
```bash
git clone https://github.com/your-username/moviedex.git
cd moviedex
npm install
```

### 2️⃣ Environment Setup
```bash
cp .env.example .env
```
*(Add your TMDB and Firebase keys to the `.env` file!)* 🔑

### 3️⃣ Action! 🎬
```bash
npm run dev
```
Open `http://localhost:5173` and grab your popcorn! 🍿
